# 方法、参数与解释边界

## 成员云与空间项

每个实体仅使用节点成员，不把背景源纳入其固有宽度。稳健散布矩阵S由源对差矢量构造，经中位长度截尾及维数校准；先求稳健pilot，再以其白化距离重新计算权重。该矩阵单位是位置或速度平方，描述成员分布，不是中心估计误差。具体确定性计算见sri_preprocess/fixed_components.py。

对实体i,j，H=sqrt(S_i)+sqrt(S_j)，将两云用同一H逆变换。d是双向最近邻距离中位数的平均，再除sqrt(维数)。Smem沿该距离的MST平均1/sqrt(1+(d/a)^2)，其中a=spatial_mem_scale，默认2。可选背景支持通过源指派与100次视线保持旋转对照估计增益，仅允许支持性增益。

Scen采用物理XYZ中心MST，只检查物理最长边L。b是其余树边长度的Q75（线性插值）。沿被测方向u，对每个实体计算w_i=sqrt(u^T S_i u)。W_e是被测两端宽度和，W_ref是其余树边两端宽度和的中位数，所有宽度均沿同一被测方向。

    B = max(b, W_e, W_ref)
    Scen = sqrt(min(1, B/L))

不使用有限参考系数或额外1/2响应尺度。Scen与Smem共享稳健散布估计；投影延展与H度量的射线半径含义不同，不强行等同。所有中心相同时Scen=1。

## 三维中心与误差

由源级Gaia视差和自行重算Vra、Vdec。分别取有效Vra、Vdec、RV中位数，在实体平均视线方向旋转为UVW。宽天区方向变化和RV非随机缺失仍是代表值近似的限制。二维Vmem的模型输运不用于三维中心。

每个分量：

    I = sum(1/error_i^2)
    sigma_sys^2 = 1/I + s_int^2/N_valid

RV有效源需RV和正有限误差；切向使用各自有效源。s_int为代码的额外散布估计。将三分量系统误差对角矩阵按相同代表方向旋转为UVW协方差。分量独立与中心误差近似需保留在解释中，不能称为严格中位数抽样协方差或完整成员三维弥散。

Vcen固定名义UVW物理MST的最长边L，以其余正长度树边的Q75为b。将差额L-b对所有实体中心的梯度与各自UVW协方差相乘求和，得到sigma_delta²；共享端点的贡献按差额梯度计算，不能将两条边误差简单相加。Q75插值及并列参考长度的平均梯度均进入传播。

    d = max(0, L-b)/b
    q = sigma_delta²/b²
    d_eff² = min(d²,1) + max(d²-1,0)/(1+q)
    Vcen = 1/sqrt(1+d_eff)

误差只缓和超额部分。d>1时即使误差趋于无穷，Vcen上限也为1/sqrt(2)。全零误差恢复sqrt(b/L)，不将协方差当成员云宽度。全部中心相同取1；最长边为正但无正参考边时明确报错，不填任意小尺度。中心误差近似和名义树选择的不确定性不是此解析传播已完整覆盖的内容。

## Cross与聚合

Cross通过留一实体的空间仿射速度预测检验关联；训练影响权重只使用训练实体，固定几何放大因子，方向系统误差进入预测残差缓和。残差处理细节由sri/core.py中affine_weights、_influence_weights、_sqrt_resolved_measurement_loss给出。四个有效实体足以执行正则化预测，但不保证留一空间几何可辨识；输出cross_geometry_status明确标记正则化依赖。

每个留一损失记作loss_i，D=mean(sqrt(loss_i))：

    Cross = 1/sqrt(1+(D/h_cross_kms)^2)
    S = Smem                         (M_RV<3)
        sqrt(Smem*Scen)               (M_RV>=3)
    V = Vmem                         (M_RV<3)
        sqrt(Vmem*Vcen)               (M_RV>=3)
    R0 = 2*S*V/(S+V)
    SRI = R0                         (M_RV<4)
          R0*Cross         (M_RV>=4)

零分边界按连续极限实现。Cross不保证单个异常的影响严格限制在1/M以内，不作这样的统计承诺。

## 参数清单

可调评分默认值集中在config/defaults.json。构造层固定约定在下表披露，并非均为用户开关；不建议为指定对象调参数。

| 参数 | 默认 | 含义 |
|---|---:|---|
| 有效RV源数 | 3 | 三维实体可用性 |
| 实体合并空间/切向归一化条件 | <=1 | 局部接触与投影速度云相容 |
| 速度投影方向网格 | 720 | 合并判定的有限角度近似 |
| RV合并否决 | Z_RV>3 | 共同径向差相对合成中心误差；不是典型速度差的3倍 |
| KPD相对间隔 | >3 | 最长对次长，并在空间/二维加入云宽度保护 |
| 空间成员邻接尺度 | 2 | Smem归一化距离响应的尺度 |
| Cross速度响应尺度 | 5 km/s | 固定物理响应约定 |
| 仿射正则 | 0.1 | 留一空间预测的岭正则约定 |
| 背景旋转数 | 100 | 可选空间桥接增益对照 |
| Gold/Silver分界 | 0.7/0.5 | SRI分级约定，不是概率阈值 |

KPD空间及二维通道复用成员云的共享H距离；宽度保护采用同一H度量的单位尺度1/sqrt(维数)，空间为1/sqrt(3)，二维为1/sqrt(2)。该尺度是度量约定，不是中心误差或置信区间。Scen保留方向投影延展，两者共享底层稳健散布矩阵，但因被测距离不同而不强制使用同一最终标量。空间/二维参考=max(次长边,被测边宽度,其余边宽度中位数)，三维则直接用次长速度边。

存在精确合并代价并列时按标签确定顺序；存在主体实体数与星数均并列、或缺RV归属距离精确并列时明确不确定。所有阈值均为明示约定，程序不从输入目录质量分布自动拟合门槛。
